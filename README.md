## 📌 Project Overview

Smart Traffic Violation & Fine Management System is a Java-based web application designed to manage traffic violations, vehicle records, and fines efficiently.

### ✨ Features
- 🔐 Admin Login
- 🚗 Vehicle Management
- 🚦 Traffic Violation Management
- 💰 Fine Management
- 🔍 Search Functionality
- 📊 Dashboard for Monitoring Records
- 🗄️ MySQL Database Integration

### 🛠️ Technologies Used
- Java
- JSP & Servlets
- HTML & CSS
- MySQL
- Apache Tomcat
- Docker
- Render (Deployment)
